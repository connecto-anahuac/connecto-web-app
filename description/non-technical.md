# Connecto — 非技術者向けプロジェクト紹介

## A. 短い概要

Connectoは、学生の履修・成績データをもとに、「学生がこれまで何を学び、次にどの授業を開講すべきか」を見える化する大学向け学務支援Webアプリです。CSVデータの取り込みから学生検索、個別の履修状況確認、開講候補の選定までを一つにつなげたプロトタイプです。

## B. 技術アピール

- **複雑な学務情報を一画面に集約**：学生、成績、カリキュラム、前提科目、開講候補を関連付け、担当者が判断に必要な情報へ素早くたどり着けるようにしました。
- **開講判断を業務ルールから支援**：単なる一覧表示ではなく、合格済み科目と前提科目を照合し、各授業を履修できる学生数を自動で算出します。
- **大量データを扱いやすい操作設計**：キーワード検索、複数条件の絞り込み、よく使う条件のプリセット、一覧・カード表示を組み合わせています。
- **現場での導入を意識したデータ取り込み**：既存のCSVファイルをドラッグ＆ドロップで登録し、学生情報と成績情報へ変換できる流れを設計しました。
- **継続的に育てられるUI**：共通部品とデザインルールを整え、画面追加時にも見た目と操作感をそろえやすい構成にしています。
- **利用環境への適応**：スペイン語の業務画面を実装し、特定地域・組織の運用に合わせてプロダクトを設計できることを示しています。

## C. 800文字程度の説明

Connectoは、大学の学務担当者が学生の履修状況を把握し、次学期の開講計画を立てる仕事を支援するWebアプリです。学務の現場では、学生名簿、成績、カリキュラム、前提科目などが別々の表で管理されると、情報を照合するだけでも時間がかかります。さらに、ある授業を受けられる学生が何人いるかを判断するには、一人ずつ合格科目と前提条件を確認する必要があります。本プロジェクトでは、その流れをCSVデータの取り込みから検索、確認、選定まで一つの体験として設計しました。

利用者は学生を名前、在籍状況、学期、学科などで検索・絞り込みでき、個別画面では履修科目、成績、単位、前提科目を一覧で確認できます。開講計画画面では、各科目について「まだ合格していない」「必要な前提科目を修了している」という条件を自動で照合し、履修可能な学生数を学期別に表示します。候補科目は画面上で選択できるため、判断材料の収集から計画作成までを連続して進められます。また、既存業務との接続を考え、CSVファイルのドラッグ＆ドロップと複数ファイルの連続処理に対応し、取り込み前に学科やファイル種別を確認・修正できる画面も用意しました。データはブラウザ内に保存するため、試作段階でも外部サーバーを準備せず、操作と業務の流れを検証できます。

画面は情報量が多くても迷いにくいよう、検索条件のプリセット、一覧とカードの使い分け、色による科目識別、処理中・エラー時の表示を用意しています。利用現場に合わせたスペイン語UIも実装しました。Connectoは、見栄えのよい画面を作るだけでなく、複雑な業務ルールを整理し、利用者の判断時間を短縮する形へ落とし込む力を示すプロジェクトです。企画、情報設計、画面設計、データ処理を一貫して考え、将来の機能追加にも対応しやすい土台まで作り込んでいます。
