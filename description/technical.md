# Connecto — 技術者向けプロジェクト紹介

## A. 短い概要

Connectoは、Next.js App Router、React、TypeScriptで構築した大学向け学務支援Webアプリです。CSVから学生・成績・カリキュラムを取り込み、IndexedDBへ保存し、履修状況の検索・可視化と前提科目を考慮した開講候補算出をブラウザ上で行います。

## B. 技術アピール

- **関心を分離したレイヤー設計**：`app`、`features`、`components`、`shared`、`external`に責務を分け、UIからDBまでの依存方向を明確化しています。
- **ドメインルールの実装**：合格判定、履修済み科目の除外、再帰的な前提科目解決、循環参照の防止、学期別の履修可能者集計をサービス層に集約しました。
- **ローカルファーストなデータ基盤**：Papa ParseでCSVを解析・正規化し、Dexieのトランザクションと`bulkPut`で複数テーブルへ一括保存します。IndexedDBのスキーマはバージョン管理しています。
- **再利用可能な検索エンジン**：型付きプロパティ定義から検索・絞り込み用スキーマを生成し、正規値、表示値、検索文字列を分離。文字列、数値、列挙値、複数条件、動的選択肢に対応しています。
- **複雑なUI状態の整理**：ZustandのProvider単位ストア、TanStack Table、Container／Presenter／Hook分割により、状態・操作・表示を分離しています。
- **失敗を考慮した更新処理**：開講候補の選択では楽観的更新を行い、保存失敗時には選択状態をロールバックします。多重操作も処理中キーで抑止します。
- **UIの再現性と検証性**：Tailwind CSSとCSS変数によるデザイントークン、Storybookによるコンポーネントカタログ、Vitestによる検索・フィルター・表ロジックの単体テストを用意しています。

## C. 800文字程度の説明

Connectoは、Next.js 16のApp Router、React 19、TypeScript 5を中心に構築した、大学の履修管理と開講計画を支援するローカルファーストなWebアプリです。薄い`page.tsx`から機能単位のTemplateへ処理を委譲し、操作画面はContainer、Presenter、Hookに分割しています。コードは`app`、`features`、`components`、`shared`、`external`へ分け、画面、業務ロジック、外部I/Oの責務を整理しました。

データ取り込みではPapa ParseでCSVを読み取り、空値、学期、成績、特殊科目を正規化します。変換した学生、成績、科目、履修計画、前提科目はDexie経由でIndexedDBへ保存し、複数テーブルの更新をトランザクションと一括書き込みで処理します。スキーマはバージョン管理しています。開講候補の算出では、学生ごとの合格科目を集合化し、前提科目を再帰的に解決します。循環参照を防ぐ探索中キーと再計算を減らすキャッシュを備え、履修済み科目を除外して履修可能者を学期別に集計します。

検索機能は、型付きの項目定義から検索スキーマを生成する汎用エンジンとして設計しました。正規値、表示ラベル、検索文字列を分離し、テキスト検索、数値比較、列挙値、複数選択、動的選択肢を同じ仕組みで扱います。状態はZustand、表はTanStack Tableで管理し、開講科目の選択には楽観的更新、失敗時ロールバック、多重送信防止を実装しました。Tailwind CSSとCSS変数で表示をトークン化し、StorybookでUI部品を独立確認できます。Vitestでは検索順位、条件判定、プリセット、表示変換などの純粋ロジックをテスト対象にしています。業務要件をドメインモデルへ落とし込み、保守可能な構造と操作性を両立させた点が技術的な見どころです。
